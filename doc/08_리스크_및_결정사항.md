### 4.1 지금부터 지킬 설계 원칙 (개인용 단계에서도 적용)

공개 배포로 넘어갈 때 구조를 다시 짜지 않도록 처음부터 지킵니다.

| 원칙 | 내용 |
|------|------|
| 개인 정보 하드코딩 금지 | 테스트 계정, 개인 경로, 개인 설정을 코드·Seed에 넣지 않음. 개발용 계정은 User Secrets로 관리 |
| 사용자별 데이터 분리 | 모든 데이터는 `%LOCALAPPDATA%\MoaView\` 아래에 두고, 실행 파일 폴더에 쓰지 않음(설치 경로 권한 문제 예방) |
| 브랜드 리소스 미포함 | 서비스 로고를 앱에 넣지 않음. 실행 중에 파비콘을 받아 `icons\`에 캐시하고(`FaviconCache`, 2026-10-14 구현), 없으면 이니셜 아이콘(예: "N")으로 표시 |
| 외부 전송 없음 | 텔레메트리, 원격 로그, 계정 정보 외부 전송 없음. 공개 시 개인정보 처리 방침을 단순하게 유지 |
| 서비스 정의 데이터화 | 서비스 정보와 로그인 셀렉터를 DB/JSON으로 두어, 공개 후에는 앱을 다시 배포하지 않고 정의 파일만 업데이트할 수 있게 함 |
| 다국어 대비 | UI 문자열은 `Resources/Strings.resx`(한국어 기본 문화권)로 분리(2026-10-14). 다른 언어는 `Strings.{culture}.resx`를 추가하면 위성 어셈블리로 빌드됨. 로그·예외 메시지는 개발자용이라 제외 |
| 오픈소스 라이선스 관리 | 쓰는 NuGet 패키지의 라이선스를 `THIRD-PARTY-NOTICES.md`에 기록(2026-10-14). 모두 MIT/Apache-2.0이고 WebView2 SDK만 Microsoft 재배포 허용 라이선스. 패키지를 바꾸면 함께 갱신 |
| 버전 관리 | 처음부터 SemVer, DB 마이그레이션으로 스키마 버전 관리(공개 후 업데이트 대비) |

### 4.2 공개 전환 시 추가 작업 (체크리스트)

| 구분 | 작업 |
|------|------|
| 법무 | 각 서비스 이용약관 다시 검토(임베디드 브라우저 사용, 자동 입력), 면책 고지, EULA, 개인정보 처리 방침 |
| 상표 | 앱 이름·아이콘·스크린샷에서 서비스 상표 노출 점검 |
| 배포 | 코드 서명 인증서, 또는 Microsoft Store(MSIX) 배포 검토. Velopack 업데이트 서버(GitHub Releases 등) |
| 보안 | 자격증명 저장 기능을 외부에서 점검, "자동 제출"을 기본 끔으로 유지 |
| 지원 | 문제 신고 채널(GitHub Issues), 사용자 가이드, FAQ(DRM·4K 제한 안내) |
| 품질 | 다양한 GPU(NVIDIA/AMD/Intel), Windows 10/11, 다중 모니터 테스트 |
| 소스 공개 여부 | **결정 완료 → D-16** MIT로 공개(2026-10-14) |
