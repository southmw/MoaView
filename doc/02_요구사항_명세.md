# 02. 요구사항 명세

우선순위: **M** (Must, MVP 필수) / **S** (Should, 1차 릴리스 권장) / **C** (Could, 향후)

## 1. 기능 요구사항 (Functional Requirements)

### 1.1 서비스(사이트) 관리

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| FR-SVC-01 | 기본 제공 서비스 5종(Netflix, TVING, Wavve, YouTube, 치지직)을 첫 실행 시 DB에 자동 등록한다 | M |
| FR-SVC-02 | 사이드바에 서비스 목록을 아이콘과 이름으로 표시한다 | M |
| FR-SVC-03 | 서비스를 선택하면 해당 서비스의 웹 플레이어를 메인 영역에 표시한다 | M |
| FR-SVC-04 | 서비스별로 활성화/비활성화와 표시 순서(드래그 정렬)를 설정한다 | S |
| FR-SVC-05 | 사용자가 이름, URL, 아이콘을 입력해서 서비스를 직접 추가·수정·삭제한다 | S |
| FR-SVC-06 | 파비콘을 자동으로 가져와 아이콘으로 쓴다 | C |
| FR-SVC-07 | 마지막으로 보던 서비스와 URL을 기억했다가 재시작할 때 복원한다 | S |

### 1.2 계정 및 로그인 관리

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| FR-ACC-01 | 서비스별로 로그인 ID와 비밀번호를 SQLite DB에 저장한다 | M |
| FR-ACC-02 | 비밀번호는 평문으로 저장하지 않고 Windows DPAPI(CurrentUser)로 암호화한다 | M |
| FR-ACC-03 | WebView2 프로필로 쿠키·세션을 유지해서 앱을 재시작해도 로그인 상태를 유지한다 | M |
| FR-ACC-04 | 로그인 페이지를 감지하면 저장된 계정으로 ID/PW 입력란을 자동으로 채운다. **TVING·Wavve 우선 지원** (D-09) | M |
| FR-ACC-08 | 로그인 페이지가 아니어도 "로그아웃 상태"(예: 헤더에 로그인 버튼이 보임)를 감지하면 로그인 페이지로 이동해서 자동 입력한다 | M |
| FR-ACC-09 | 계정별 "자동 제출" 옵션. 켜면 입력 후 로그인 버튼까지 자동으로 누른다(기본 끔) | S |
| FR-ACC-10 | 자동 제출 반복 방지: 실패하거나 다시 로그인 화면으로 돌아오면 일정 시간 자동 제출을 멈추고 사용자에게 알린다(계정 잠금 예방) | M |
| FR-ACC-11 | 로그인 방식별 입력 지원: 서비스 자체 ID를 우선 지원하고, 소셜/제휴 로그인(CJ ONE, 네이버, 카카오 등)은 순차 지원 | S |
| FR-ACC-05 | 서비스 하나에 계정 여러 개를 등록하고, 계정마다 별도의 WebView2 프로필로 전환한다. 1차(개인용)는 서비스당 계정 1개만 쓰되, DB 스키마와 프로필 이름 규칙은 다중 계정을 그대로 수용한다(D-11) | C |
| FR-ACC-06 | 서비스별 로그아웃(쿠키 삭제)과 계정 삭제를 지원한다 | S |
| FR-ACC-07 | 앱 실행 시 마스터 PIN/Windows Hello 잠금 옵션 | C |

### 1.3 재생 및 화질

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| FR-PLY-01 | WebView2에서 DRM(Widevine/PlayReady) 보호 콘텐츠를 재생한다 | M |
| FR-PLY-02 | GPU 하드웨어 가속 디코딩을 사용한다 | M |
| FR-PLY-03 | 4K(3840×2160) 해상도 출력을 지원한다. 고 DPI(Per-Monitor V2)를 인식한다 | M |
| FR-PLY-04 | 서비스를 전환하면 이전 서비스의 재생을 자동으로 일시정지한다(옵션) | S |
| FR-PLY-05 | 오래 쓰지 않은 서비스의 WebView는 일시 중단(Suspend)해서 메모리와 CPU를 아낀다 | S |
| ~~FR-PLY-06~~ | ~~"외부 앱/Edge로 열기" 대체 경로~~ **제외(D-07)**: 모든 재생은 앱 안에서만 한다. 외부 실행 기능을 두지 않는다 | - |
| FR-PLY-07 | 미니 플레이어 모드: 창을 작은 항상 위(Topmost) 창으로 전환하고 셸 UI를 숨긴다. 단축키와 사이드바 버튼으로 토글 | S |
| FR-PLY-08 | PIP: 서비스 웹 플레이어의 Picture-in-Picture(Chromium 내장 PiP 창)가 WebView2에서 동작하게 한다. 단축키로 현재 영상을 PiP로 띄운다 | S |

### 1.4 전체화면 및 창 제어

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| FR-FS-01 | 웹 플레이어의 전체화면 버튼을 누르면 앱 창도 전체화면으로 전환한다(HTML5 Fullscreen API 연동) | M |
| FR-FS-02 | F11로 앱 전체화면(사이드바·타이틀바 숨김)을 토글한다 | M |
| FR-FS-03 | Esc로 전체화면을 해제한다 | M |
| FR-FS-04 | 다중 모니터 환경에서는 창이 있는 모니터에서 전체화면으로 표시한다 | M |
| FR-FS-05 | 창 위치, 크기, 최대화 상태를 저장하고 복원한다 | S |
| FR-FS-06 | 전체화면 중에는 마우스를 일정 시간 움직이지 않으면 커서를 숨긴다 | C |

### 1.5 탐색 및 편의 기능

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| FR-NAV-01 | 뒤로·앞으로는 단축키(Alt+←/→)와 마우스 측면 버튼(WebView2 기본 동작)으로, 새로고침·홈은 단축키(F5, Alt+Home)와 서비스 아이콘 컨텍스트 메뉴(계정 관리·홈·새로고침·로그아웃)로 제공한다. 전용 탐색 버튼과 주소 표시줄은 두지 않는다(D-10) | M |
| FR-NAV-02 | 그 밖의 전역 단축키(서비스 전환 Ctrl+1~9 등, [06 UI/UX](06_UI_UX_설계.md) 참고) | S |
| FR-NAV-03 | 즐겨찾기: 특정 콘텐츠·채널 URL을 저장하고 바로 이동 | C |
| FR-NAV-04 | 외부 도메인으로 가는 새 창 요청(팝업)은 기본 브라우저로 열고, 로그인 팝업(OAuth)은 앱 안에서 처리한다 | M |
| FR-NAV-05 | 시스템 트레이 상주와 미디어 키(재생/일시정지) 지원 | C |

## 2. 비기능 요구사항 (Non-Functional Requirements)

| ID | 분류 | 요구사항 |
|----|------|----------|
| NFR-01 | 플랫폼 | Windows 10 22H2 이상, Windows 11 / x64(지원 정책. 기술적 최소값은 `SupportedOSPlatformVersion` 10.0.17763.0). .NET 10 Desktop Runtime, WebView2 Evergreen Runtime |
| NFR-02 | 성능 | 앱 콜드 스타트 3초 이내(첫 서비스 페이지 로드 제외) |
| NFR-03 | 성능 | 로드된 서비스 사이 전환 1초 이내 |
| NFR-04 | 자원 | 서비스 1개 재생 시 앱 셸 오버헤드 200MB 이하(WebView2 렌더러 프로세스 제외) |
| NFR-05 | 보안 | 자격증명은 DPAPI로 암호화하고, 로그·예외 메시지에 비밀번호를 남기지 않는다 |
| NFR-06 | 보안 | 모든 데이터를 `%LOCALAPPDATA%\MoaView\` 아래 로컬에만 저장하고 외부로 전송하지 않는다 |
| NFR-07 | 안정성 | WebView2 렌더러 프로세스가 죽으면(ProcessFailed) 해당 서비스만 자동으로 다시 로드하고 앱은 유지한다 |
| NFR-08 | 유지보수 | 서비스별 동작(로그인 감지, 자동 입력 스크립트)을 Provider로 분리해서, 사이트 구조가 바뀌어도 해당 Provider만 고치면 되게 한다 |
| NFR-09 | 로깅 | Serilog로 파일 로그 남김(일 단위 롤링, 7일 보관) |
| NFR-10 | 배포 | 단일 설치 패키지와 자동 업데이트(Velopack 또는 MSIX) |
| NFR-11 | 법적 준수 | DRM 우회, 콘텐츠 저장, 광고 차단 기능을 넣지 않는다. 각 서비스의 공식 웹 플레이어만 사용한다 |
