# 11. 사용자 가이드

MoaView는 Netflix, TVING, Wavve, YouTube, 치지직을 한 창에서 전환하며 보는 Windows 앱입니다. 각 서비스의 **공식 웹 플레이어**를 그대로 띄우므로 로그인, 재생, 화질 선택은 그 서비스 웹사이트와 같습니다. 이 문서는 설치부터 자주 쓰는 기능, 문제 해결까지 다룹니다.

## 1. 설치

1. GitHub Releases에서 `MoaView-win-Setup.exe`를 내려받아 실행합니다. 설치기가 필요한 .NET Desktop Runtime과 Microsoft Edge WebView2 런타임을 자동으로 받아 설치합니다.
2. 코드 서명을 하지 않은 개인 프로젝트라 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"으로 진행합니다.
3. 설치 없이 쓰려면 `MoaView-win-Portable.zip`을 풀어 `MoaView.exe`를 실행합니다. 포터블 버전은 자동 업데이트가 동작하지 않습니다.

요구 사항: Windows 10 1809 이상(Windows 11 권장), 인터넷 연결.

## 2. 첫 실행

- 왼쪽 사이드바에 기본 서비스 5개가 보입니다. 아이콘을 누르면 그 서비스의 웹 페이지가 열리고, 각 서비스 사이트에서 평소처럼 로그인합니다.
- 로그인 세션(쿠키)은 서비스마다 따로 보관되어 다음 실행에도 유지됩니다.
- 사이드바 ≡(Ctrl+B)를 누르면 이름과 단축키가 함께 보이게 펼쳐집니다.

## 3. 자주 쓰는 기능

| 하고 싶은 일 | 방법 |
|--------------|------|
| 서비스 전환 | 사이드바 아이콘 클릭, Ctrl+1~9, Ctrl+Tab / Ctrl+Shift+Tab |
| 뒤로 / 앞으로 | Alt+← / Alt+→, 마우스 측면 버튼 |
| 새로고침 / 홈 | F5 또는 Ctrl+R / Alt+Home. 아이콘 우클릭 메뉴에도 있음 |
| 전체화면 | F11, 사이드바 ⛶, 또는 플레이어의 전체화면 버튼. Esc로 해제 |
| 미니 플레이어 | Ctrl+M. 작은 항상 위 창이 되며 위쪽 바를 드래그해 옮기고 모서리로 크기를 바꿈. Esc·더블클릭·Ctrl+M으로 복귀. 위치와 크기는 기억됨 |
| PiP(화면 속 화면) | Ctrl+P. 재생 중인 영상을 Windows 작은 창으로 띄움 |
| 확대/축소 | Ctrl + / Ctrl - / Ctrl 0. 서비스별로 저장됨 |
| 설정 | 사이드바 ⚙ 또는 Ctrl+, |

Space, 화살표 같은 플레이어 키는 앱이 가로채지 않고 웹 플레이어에 그대로 전달됩니다.

## 4. 계정 저장과 자동 로그인

서비스 아이콘을 **우클릭 → 계정 관리...**(또는 설정 > 계정)에서 아이디와 비밀번호를 저장하면, 세션이 끊겨 로그인 페이지가 뜰 때 자동으로 입력합니다.

- 비밀번호는 Windows 계정으로 암호화(DPAPI)되어 **이 PC의 이 Windows 계정에서만** 풀립니다. 다른 PC로 복사해도 복원되지 않습니다.
- **자동 제출**(로그인 버튼까지 자동 클릭)은 기본으로 꺼져 있습니다. 켜더라도 같은 계정은 10분에 한 번만 시도하고, 연속 2회 실패하면 계정 잠금을 막기 위해 자동으로 꺼집니다. 캡차나 2단계 인증이 있는 서비스에서는 끄는 것을 권합니다.
- 지원 범위: TVING·Wavve 자체 아이디, Netflix, 치지직(네이버). YouTube(Google)는 세션 유지만 권장합니다. 카카오·CJ ONE 같은 제휴 로그인 자동 입력은 아직 지원하지 않습니다.
- 로그아웃하려면 아이콘 우클릭 → **로그아웃 (쿠키 삭제)**. 저장된 계정이 있으면 바로 로그인 페이지로 가서 자동 입력합니다.

## 5. 설정

| 탭 | 내용 |
|----|------|
| 일반 | 시작 서비스(마지막에 보던 것 / 고정), 테마(다크·라이트·Windows 따름), 닫기(X)를 트레이로 보내기 |
| 서비스 | 표시 여부, 순서(행을 끌어 놓거나 위/아래), 전환 시 일시정지, 서비스 추가·수정·삭제 |
| 계정 | 서비스별 계정 요약과 관리 |
| 재생 | 보지 않는 서비스를 절전하기까지의 시간, 동시에 살려 둘 서비스 수 |
| 단축키 | 전체 단축키 목록 |
| 데이터 | 데이터·로그 폴더 열기, DB 백업, 모든 서비스 쿠키·캐시 초기화, 모든 데이터 초기화(처음 상태로) |
| 정보 | 버전, WebView2 런타임 버전, 업데이트 확인 |

### 사용자 정의 서비스 추가

사이드바 ＋ 또는 설정 > 서비스 > 추가에서 이름과 홈 URL(예: `https://www.disneyplus.com/`)을 넣으면 사이드바에 추가됩니다. 재생이 되는지는 그 서비스가 Edge(WebView2) 브라우저를 허용하는지에 달려 있습니다. 고급 항목(로그인 URL, 허용 호스트)은 보통 비워 둬도 됩니다.

### 트레이 아이콘

앱이 실행 중이면 작업 표시줄 알림 영역에 MoaView 아이콘이 있습니다. 클릭하면 창을 숨기거나 다시 띄우고, 우클릭 메뉴에서 열기·설정·종료를 고를 수 있습니다. 설정 > 일반에서 "닫기(X)를 누르면 종료하지 않고 트레이로 보냄"을 켜면 X를 눌러도 앱이 계속 실행되며(재생도 계속됨), 정말 끝내려면 트레이 메뉴의 종료를 씁니다.

### 모든 데이터 초기화

설정 > 데이터 > **모든 데이터 초기화**는 서비스 목록·설정·저장된 계정·쿠키·캐시·아이콘을 모두 지우고 처음 실행 상태로 돌립니다. 되돌릴 수 없으니 필요하면 먼저 DB 백업을 받아 두세요. 실행 중에는 지울 수 없어 앱을 다시 시작할 때 지워집니다.

### 절전과 메모리

영상을 재생하는 서비스는 하나당 약 1 GB 메모리를 씁니다. 보지 않는 서비스는 기본 5분 뒤 절전되고, 동시에 3개까지만 살려 둡니다(초과하면 가장 오래 안 본 것부터 닫음). 닫힌 서비스는 다시 열면 마지막으로 보던 페이지에서 이어집니다. 설정 > 재생에서 바꿀 수 있습니다.

## 6. 업데이트

설치 버전은 시작 10초 뒤 새 버전을 확인해 미리 받아 두고, 준비되면 상단에 "다시 시작" 배너를 띄웁니다. 재생 중이면 나중에 설정 > 정보 > **다시 시작해 적용**을 누르면 됩니다.

## 7. 데이터와 개인정보

모든 데이터는 `%LOCALAPPDATA%\MoaView\`에만 있습니다.

| 폴더·파일 | 내용 |
|-----------|------|
| `moaview.db` | 서비스 목록, 설정, 암호화된 계정 |
| `WebView2\` | 서비스별 로그인 세션(쿠키)과 브라우저 캐시 |
| `logs\` | 앱 로그(7일 보관), 크래시 로그(`crash-*.log`) |
| `icons\` | 사이드바 아이콘으로 쓰는 각 사이트의 파비콘 |

앱은 어떤 정보도 외부로 보내지 않습니다(업데이트 확인을 위한 GitHub 접속 제외). 로그에는 비밀번호와 URL의 토큰 부분을 남기지 않습니다. 완전히 지우려면 앱을 종료하고 이 폴더를 삭제하면 됩니다.

## 8. 문제 해결

| 증상 | 확인할 것 |
|------|-----------|
| 특정 서비스 화면이 검게 나오거나 안 열림 | 회사·학교 네트워크가 그 서비스를 막는지 확인. 아이콘 우클릭 → 새로고침 |
| "WebView2 런타임이 필요합니다" | 안내에 따라 설치하거나 Microsoft 다운로드 페이지에서 Evergreen 런타임을 설치한 뒤 다시 실행 |
| 화질이 기대보다 낮음 | 서비스가 브라우저에 허용하는 최대치입니다. Netflix는 WebView2에서 1080p까지이며 4K(하드웨어 DRM)는 지원하지 않습니다. 치지직은 그리드(네이버 라이브 스트리밍 커넥터 + 확장)가 없으면 720p입니다 |
| 자동 입력이 되지 않음 | 계정 관리에서 "로그인이 끊기면 자동 입력"이 켜져 있는지, 비밀번호가 저장됐는지 확인. 자동 제출이 꺼졌다는 배너가 떴으면 비밀번호를 고친 뒤 다시 켜기 |
| 로그인 상태가 자꾸 풀림 | 설정 > 데이터 > 모든 서비스 데이터 초기화 후 다시 로그인 |
| 앱이 뜨지 않음 | 이미 실행 중이면 기존 창이 앞으로 옵니다. 그래도 안 보이면 작업 관리자에서 MoaView를 끝내고 다시 실행 |
| 오류 창이 반복됨 | `logs\` 폴더의 당일 로그와 `crash-*.log`를 GitHub Issues에 첨부해 알려 주세요. 로그에는 비밀번호가 들어가지 않습니다 |

## 9. 하지 않는 것

스트림 주소 추출, DRM 우회, 다운로드·녹화, 광고 차단, User-Agent 위장은 하지 않습니다. 각 서비스 약관을 지키는 범위에서 공식 웹 플레이어를 편하게 모아 보는 것이 이 앱의 전부입니다.
