## 핵심 요약

1. **구현 방식**: 각 서비스의 공식 웹 플레이어를 **WebView2(Chromium 기반 Edge)** 안에 띄우는 "통합 브라우저 셸" 방식. 영상 스트림을 직접 가로채거나 DRM을 우회하지 않습니다.
2. **최대 리스크(해소)**: Netflix·TVING·Wavve는 DRM(Widevine/PlayReady)으로 보호됩니다. PoC에서 **세 서비스 모두 WebView2 재생에 성공**했고(Netflix·TVING 1080p), WebView2에 PlayReady 하드웨어 DRM이 있음을 확인했습니다([09 PoC 결과](09_PoC_결과.md)).
3. **4K 현실**: 앱 자체는 4K 렌더링을 지원하지만, 실제 해상도는 서비스 정책(DRM 보안 수준, 요금제, 코덱, HDCP)에 따라 정해집니다. YouTube는 4K가 가능하고, Netflix 4K는 WebView2에서 어려울 가능성이 높습니다(상세: [03 기술 검토](03_기술_검토.md)). 그래도 **모든 재생은 앱 안에서만** 하고 외부 브라우저·앱으로 넘기는 기능은 두지 않습니다(D-07). 치지직은 PoC에서 그리드 없이 **720p**까지 재생을 확인했고, 1080p는 그리드(확장 + 네이버 라이브 스트리밍 커넥터)가 필요합니다. WebView2에서 공식 확장 로드와 커넥터(Native Messaging) 통신까지 확인했으며, 1080p 선택 여부는 미확인입니다([03 기술 검토](03_기술_검토.md) 3.1절, [09 PoC 결과](09_PoC_결과.md) P5-b).
4. **로그인 정보**: SQLite에 저장하되 비밀번호는 **Windows DPAPI로 암호화**합니다. 로그인 세션은 WebView2 프로필(쿠키)로 유지해서 매번 다시 입력하지 않게 합니다.
5. **배포 범위**: 1차는 개인용이고 나중에 공개 배포로 전환할 수 있습니다. 공개 전환에 대비해 브랜드 로고 미포함, 개인 정보 하드코딩 금지, 외부 전송 없음 같은 원칙을 처음부터 지킵니다([08 문서](08_리스크_및_결정사항.md) 4절).
