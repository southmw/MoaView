**Go/No-Go 기준**
- Go: DRM 서비스(Netflix/TVING/Wavve) 중 2개 이상 WebView2에서 재생 가능
- 조건부 Go: DRM 서비스가 재생되지 않으면 YouTube·치지직 중심으로 범위를 줄이고, 재생이 안 되는 DRM 서비스는 지원 목록에서 제외(외부 실행 대체 없음, D-07)
- No-Go: 사실상 모든 서비스가 막힘(가능성 낮음)

## 4. 개발 규칙

- 브랜치: `main`(릴리스) / `develop` / `feature/*`
- 커밋: Conventional Commits, 영어(예: `feat(player): add fullscreen sync with WebView2`)
- 빌드 확인 후 커밋(`dotnet build`, `dotnet test`)
- Nullable 활성화, 비동기 메서드는 `Async` 접미사, DI와 Options 패턴 사용
- 민감 정보(테스트 계정 등)는 User Secrets로 관리하고 커밋하지 않음
- 설계가 바뀌면 `Doc/` 문서를 함께 갱신
