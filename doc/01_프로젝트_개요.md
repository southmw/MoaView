# 01. 프로젝트 개요

## 1. 프로젝트명

**MoaView** (모아 + View. 2026-10-13 확정, D-15. 개발 중 임시 이름은 MyOTTPlayer)

## 2. 배경 및 문제

- 국내 사용자는 보통 여러 OTT·스트리밍 서비스를 함께 구독하고 이용합니다(Netflix, TVING, Wavve, YouTube, 치지직 등).
- 서비스마다 브라우저 탭, 앱, 로그인 상태가 따로 있어서 전환이 번거롭습니다.
- 브라우저 탭으로 시청하면 다른 웹 작업과 섞이고, 전체화면·단축키·창 관리가 서비스마다 다릅니다.

## 3. 목적

> **여러 OTT 미디어를 하나의 Windows 프로그램에서 전환하며 시청할 수 있게 한다.**

| 목표 | 설명 |
|------|------|
| 통합 접근 | 사이드바에서 클릭 한 번으로 서비스 전환 |
| 로그인 유지 | 사이트 정보와 로그인 정보를 로컬 SQLite3로 관리하고, 세션을 유지 |
| 고화질 시청 | 4K 해상도 출력과 하드웨어 가속 지원(서비스 정책 범위 안에서) |
| 몰입형 시청 | 전체화면, 단축키, 일관된 창 제어 |

## 4. 범위

### 4.1 포함 (In Scope)

- .NET 10 기반 WPF 데스크톱 애플리케이션
- WebView2로 각 서비스의 공식 웹 플레이어 호스팅
- 기본 제공 서비스 5종과 사용자 정의 서비스 추가
- 로컬 SQLite3 DB에 서비스 정보, 계정 정보, 앱 설정 저장
- 비밀번호 암호화 저장(DPAPI)과 로그인 폼 자동 입력 보조
- 전체화면(앱 전체화면, 영상 전체화면 연동)
- 4K 모니터 대응(고 DPI, 하드웨어 가속)

### 4.2 제외 (Out of Scope)

- **DRM 우회, 스트림 추출, 다운로드/녹화 기능** (법적·약관 위반)
- 광고 차단 기능(서비스 약관 위반 소지)
- 통합 검색, 통합 시청 기록 수집(각 서비스의 공식 API가 없음, 향후 검토)
- macOS/Linux/모바일 지원
- 서버 연동, 클라우드 동기화(모든 데이터는 로컬에만 저장)

## 5. 대상 서비스 (초기)

| 서비스 | 유형 | URL | DRM | 비고 |
|--------|------|-----|-----|------|
| Netflix | VOD | https://www.netflix.com/browse | 있음 (Widevine/PlayReady) | 4K는 PlayReady 하드웨어 DRM 필요 |
| TVING | VOD + 실시간 TV | https://www.tving.com | 있음 | 실시간 채널 포함 |
| Wavve | VOD + 실시간 TV | https://www.wavve.com | 있음 | 실시간 채널 포함 |
| YouTube | VOD + 라이브 | https://www.youtube.com | 일반 영상은 없음 | 4K/8K(VP9/AV1) 가능 |
| 치지직 (CHZZK) | 라이브 스트리밍 | https://chzzk.naver.com | 없음 | 네이버 로그인. PC에서 1080p는 그리드(확장 + 네이버 라이브 스트리밍 커넥터) 필요, 미설치 시 720p(PoC 실측) |

향후 후보로 쿠팡플레이, 디즈니+, 왓챠, SOOP(아프리카TV), Twitch, 라프텔이 있으며, 사용자 정의 서비스 추가 기능으로도 대응할 수 있습니다.

## 6. 대상 사용자 및 배포 범위

| 단계 | 배포 범위 | 대상 |
|------|-----------|------|
| 1차 | **개인용** | 개발자 본인 |
| 2차 (추후 검토) | 공개 배포 | 일반 사용자 |

> 공개 배포로 전환할 것에 대비한 설계 원칙과 전환 체크리스트: [08 리스크 및 결정사항](08_리스크_및_결정사항.md) 4절

- 여러 OTT를 구독하는 사용자
- 4K 모니터나 TV를 PC에 연결해서 시청하는 사용자
- 서비스 사이 이동이 잦은 라이브 스트리밍 시청자

## 7. 성공 기준

| 기준 | 목표 |
|------|------|
| 대상 서비스 재생 | 5종 중 DRM이 걸린 서비스까지 포함해 정상 재생 |
| 서비스 전환 시간 | 이미 로드된 서비스는 1초 이내 |
| 재로그인 빈도 | 서비스 세션이 만료되기 전까지 재로그인 없음 |
| 4K 출력 | YouTube 4K(2160p) 영상을 끊김 없이 재생 |
| 전체화면 | 앱 전체화면과 영상 전체화면 모두 단축키 하나로 전환 |
